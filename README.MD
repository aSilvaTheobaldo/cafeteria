# ☕ Site da Cafeteria

Bem-vindo ao projeto do site da nossa cafeteria!

Este projeto tem como objetivo criar uma experiência agradável, moderna e intuitiva para apresentar a cafeteria, seus produtos e serviços.

## 📖 Sobre o projeto

O site foi desenvolvido para apresentar a cafeteria e facilitar o acesso dos clientes ao nosso cardápio, informações sobre o estabelecimento e formas de contato.

A proposta é transmitir, através do design e do conteúdo, a sensação de um ambiente acolhedor, perfeito para tomar um bom café, encontrar amigos ou simplesmente aproveitar um momento tranquilo.

## ✨ Funcionalidades

- 🏠 Página inicial
- ☕ Cardápio de cafés
- 🥐 Doces e lanches
- 📍 Localização
- 🕐 Horário de funcionamento
- 📞 Informações de contato
- 📱 Layout responsivo

## 🛠️ Tecnologias

O projeto utiliza inicialmente:

- HTML5
- CSS3
- JavaScript
